# Reproducibility Documentation

This directory contains all the code and pipelines used to generate the results in the *cobraa* publication. The workflows are organized into three main components, each with its own Snakefile and documentation.

## Overview

The reproducibility framework consists of three interconnected pipelines:

1. **mhsfiles/** - Data preprocessing pipeline
2. **simulations/** - Method validation pipeline  
3. **inference_realdata/** - Main analysis pipeline

## Pipeline Descriptions

### 1. MHS Files Generation (`mhsfiles/`)

**Purpose**: Convert raw sequencing data into the multi-hetsep (mhs) format required by cobraa.

**Input**: CRAM/BAM files from 1000 Genomes Project (30X coverage, GRCh38)

**Output**: mhs files (one per chromosome, per individual)

**Key Steps**:
- Convert CRAM → BAM
- Call variants with quality filters
- Apply mappability masks
- Generate mhs format files

**Documentation**: See `mhsfiles/README.md` for detailed pipeline documentation.

**When to use**: Run this pipeline when you need to process new sequencing data (CRAM/BAM files) into mhs format.

### 2. Simulations and Validation (`simulations/`)

**Purpose**: Validate the cobraa method using simulated data with known demographic parameters.

**Input**: Demographic model specifications (population sizes, admixture times, admixture fractions)

**Output**: 
- Simulated mhs files
- Inference results (PSMC and cobraa)
- Parameter recovery assessments

**Key Steps**:
- Simulate genetic data using msprime
- Run PSMC inference (panmictic model)
- Run cobraa inference with known time pairs
- Search across all possible (ts, te) pairs to test identifiability

**Documentation**: See `simulations/README.md` for detailed pipeline documentation.

**When to use**: 
- Testing the method with new parameter combinations
- Validating changes to the cobraa algorithm
- Understanding parameter identifiability
- Comparing structured vs. panmictic models

### 3. Real Data Inference (`inference_realdata/`)

**Purpose**: Infer population size histories and archaic admixture for real human genomes.

**Input**: mhs files from 1000 Genomes Project (generated by mhsfiles/ pipeline)

**Output**:
- Inferred demographic parameters (N_A(t), N_B, γ, T₁, T₂)
- Log-likelihood values for model comparison
- Decoded ancestry tracts (optional)

**Key Steps**:
- Run cobraa across grid of (ts, te) time pairs
- Compare structured vs. panmictic models
- Identify maximum likelihood parameters
- Decode genome to identify archaic ancestry segments

**Documentation**: See `inference_realdata/README.md` for detailed pipeline documentation.

**When to use**: Run this pipeline to analyze real human genomic data and infer demographic history.

## Quick Start Guide

### Step 1: Set Up Environment

```bash
# Create conda environment with required packages
conda create --name cobraa
conda activate cobraa
conda install numpy numba pandas joblib scipy psutil matplotlib

# Clone the repository
git clone https://github.com/trevorcousins/cobraa.git
cd cobraa
```

### Step 2: Choose Your Workflow

#### Option A: Process New Data

If you have CRAM/BAM files to analyze:

```bash
cd reproducibility/mhsfiles
# Edit Snakefile to point to your data
snakemake -s Snakefile --cores 8
```

#### Option B: Run Simulations

To validate the method or test new parameters:

```bash
cd reproducibility/simulations
# Edit Snakefile to configure simulation parameters
snakemake -s Snakefile --cores 8
```

#### Option C: Analyze Real Data

If you already have mhs files:

```bash
cd reproducibility/inference_realdata
# Edit Snakefile to configure analysis
snakemake -s Snakefile --cores 8
```

## Configuration Notes

### Path Modifications

The Snakefiles contain hardcoded paths specific to the original analysis environment. You will need to modify these paths to match your system:

**Common paths to update:**
- Input data directories (CRAM/BAM locations)
- Output directories
- Reference genome paths
- Script locations
- Sample metadata files

### Parameter Customization

Each Snakefile includes configurable parameters at the top:

**mhsfiles/**:
- Populations and samples to process
- Quality thresholds
- Chromosomes to include

**simulations/**:
- Demographic model parameters (N, μ, ρ, L)
- Admixture parameters (γ, ts, te)
- Number of replicates
- Search ranges for time pairs

**inference_realdata/**:
- Time pair search ranges
- Model constraints
- Convergence criteria
- Decoding options

## Computational Resources

These pipelines were designed for high-performance computing (HPC) environments:

**Memory requirements:**
- mhsfiles/: Moderate (BAM processing)
- simulations/: High (200-355GB for large simulations)
- inference_realdata/: Moderate (binning reduces memory)

**Parallelization:**
- All pipelines support parallel execution via Snakemake
- Natural parallelization by sample, chromosome, or parameter combination
- Recommended to use HPC job schedulers (SLURM, etc.)

**Runtime:**
- mhsfiles/: Hours to days (depends on sequencing depth)
- simulations/: Hours per simulation + inference
- inference_realdata/: Hours to days (depends on genome size and iterations)

## Output Files

### Inference Outputs

All inference pipelines produce:

**final_parameters.txt**: Main output file with D rows and 4 columns:
1. Left time boundary
2. Right time boundary  
3. Coalescence rate in population A
4. Coalescence rate in population B

**log.txt**: Detailed log including:
- Iteration-by-iteration updates
- Log-likelihood values
- Parameter updates
- Convergence information

### Decoding Outputs

Chromosome-level files with columns:
- Genomic position
- Posterior probabilities for each state
- Most likely state assignment

## How to Interpret Results

### Model Comparison

Compare log-likelihoods between models:
- Higher log-likelihood = better fit
- Compare structured (cobraa) vs. panmictic (PSMC)
- Use likelihood ratio tests for statistical comparison

### Parameter Conversion

Results are in coalescent units. Convert to real units:

**Time boundaries** (in generations):
```
time_generations = boundary / mutation_rate
time_years = time_generations * generation_time
```

**Effective population size**:
```
Ne = (1 / coalescence_rate) / mutation_rate
```

**Recommended values for humans**:
- mutation_rate (μ): 1.25e-8 per base per generation
- generation_time: 25-30 years

### Admixture Parameters

- **γ (gamma)**: Fraction of ancestry from population B (0 to 0.5 in these analyses)
- **T₁ (ts)**: Time of admixture event (more recent)
- **T₂ (te)**: Time of population split (more ancient)

## Troubleshooting

### Common Issues

**Issue**: Snakemake can't find input files
- **Solution**: Update hardcoded paths in Snakefile to match your system

**Issue**: Out of memory errors
- **Solution**: Increase `b` (bin size) parameter to reduce memory usage

**Issue**: Slow convergence
- **Solution**: Check log file for parameter updates; may need to adjust bounds or starting values

**Issue**: Import errors for cobraa
- **Solution**: Ensure cobraa.py path is correct in shell commands
